Questions, answered.

Can I export AI and EPS files from Figma with Brandfig?

Yes. AI files are PDF-compatible and open as vectors in Illustrator. EPS files are made from the vector logo. Pictures and angular gradients can’t go in an EPS. Read the logo export guide for every format.

Which logo files should I give a client?

Vector files for print and design work (AI, EPS, PDF, SVG) and PNG or JPG for everyday screen use, in colour, reversed, black and white. Read the logo package guide.

How will the client know which file to use?

Add the Which file to use PDF. It explains each format, size and colour version, the logo rules and where to find every file.

Which PNG sizes can I export?

Presets from 256 to 4096 px wide, and any custom width.

Can the brand guidelines go in the same zip?

Yes, as a PDF, along with a font list. Build them first with the Guidelines tool.
